# Задание на восьмое практическое занятие

1. Напишите функцию ```my_strstr(char*, char*),``` которая ищет первое вхождение подстроки в строке.
2. Реализуйте функцию ```void reverse_string(char*)```, которая переворачивает строку на месте.
3. Напишите функцию ```int is_palindrome(char*)```, которая проверяет, читается ли строка одинаково в обоих направлениях (игнорируя регистр и пробелы).
4. Реализуйте функцию ```char* int_to_string(int number)```, которая преобразует целое число в строку.
5. Напишите функцию ```int string_to_int(char*)```, которая преобразует строку в целое число (аналог atoi).
6. Напишите функцию, ```char* get_max_length_string(char*)```, которая находит самое длинное слово в строке и возвращает указатель на него.
7. Реализуйте алгоритм сжатия Run-Length Encoding: "AAABBBCC" → "A3B3C2". Функция ```char* RLE(char*)``` принимает на вход исходную строку и возвращает новую сжатую строку.
8. Реализуйте функцию ```char* RLD(char*)```, которая выполняет обратное предыдущему заданию преобразование.
9. Напишите функцию ```int is_anagram(char*, char*)```, которая проверяет, являются ли две строки анаграммами друг друга.
